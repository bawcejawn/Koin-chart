# Koin-chart

Free live price chart for the KoinDX **VHP/KOIN** pool on Koinos
(pair `1NqLghiFRwkXZR7NBFHHiCJkF5gLHyJap1`).

Live page: https://bawcejawn.github.io/Koin-chart/

- Candles/line at 15m, 1h, 4h, 1D with KOIN volume
- Price flip (KOIN per VHP / VHP per KOIN), 24h change, reserves
- USD estimate from the KoinDX KOIN/vUSDT pool
- Data comes straight from the public Koinos RPC (`api.koinos.io`); no keys, no backend
- Auto-refreshes every 30s; history is cached in your browser

Charts by [TradingView Lightweight Charts](https://github.com/tradingview/lightweight-charts).
