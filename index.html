Loop trades

Routes through several KoinDX pools that end with more KOIN (or VHP) than they start with. Every route is re-checked on the blockchain before it's shown.

Not scanned yet.

How a loop runs: all swaps go out as one transaction with a minimum return. If any pool changed so you'd get back less than that minimum, the whole thing cancels. You keep your tokens and only use some mana, which recharges. Loops are usually small, because they only appear after someone makes a lopsided trade.

Earn fees as a liquidity provider
